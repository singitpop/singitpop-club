## 📋 Email Response Guidelines

### privacy@singitpop.com
**Expected Requests:**
- GDPR data access requests ("What data do you have on me?")
- Data deletion requests ("Delete my account")
- Cookie consent questions
- Privacy policy clarifications

**Response Time:** Within 30 days (GDPR requirement)

**Template Response:**
```
Subject: Re: Privacy Inquiry

Dear [Name],

Thank you for contacting us regarding [topic].

[Answer their question]

For more information, please see our Privacy Policy: https://singitpop.club/privacy

If you have further questions, please don't hesitate to ask.

Best regards,
SingIt Pop Privacy Team
```

## 🔐 Security

### Phishing Protection
- Never ask for passwords via email
- Don't click suspicious links
- Verify sender before responding to "urgent" requests

### Data Protection
- Don't send personal data unencrypted
- Use secure file transfer for GDPR data exports
- CC legal@singitpop.com on sensitive matters
